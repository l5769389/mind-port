# Rendering

MindPort rendering has three goals: readable previews, structured SVG output, and stable SDK behavior.

MindPort 渲染目标是：预览可读、SVG 结构化、SDK 行为稳定。

## Modes

- `preview`: prefer embedded official previews when available, currently mainly XMind thumbnails.
- `semantic`: parse and render structured SVG.
- `editable`: keep structured AST and raw fields for future editor workflows; rendering follows semantic mode.

## Themes

`theme: "mindport"` is the v1-ready default for high-level APIs such as `render()` and `renderSvg()`.

```ts
const svg = renderSvg(parsed, {
  theme: "mindport",
  compatibilityMode: "semantic"
});
```

Available built-in themes:

- `mindport`: professional neutral defaults for app and document previews.
- `default`: legacy light theme.
- `ink`: high-contrast monochrome theme.

You can also pass a partial theme object:

```ts
renderSvg(parsed, {
  theme: {
    background: "#ffffff",
    nodeFill: "#ffffff",
    nodeStroke: "#d0d7e2",
    text: "#172033"
  }
});
```

## XMind Presets

Use `stylePreset: "xmind"` when you want XMind-like branch weight, boundaries, and summaries.

```ts
renderSvg(parsed, {
  stylePreset: "xmind",
  renderSettings: {
    relationshipStyle: "xmind"
  }
});
```

## ProcessOn Styles

Use `stylePreset: "processon"` for ProcessOn mind-map rendering. By default, MindPort reads the file structure and theme first.

```ts
renderSvg(parsed, {
  stylePreset: "processon",
  structureStyle: "auto",
  processOnStyle: "file",
  canvasBackground: "#ffffff",
  watermark: "none"
});
```

`structureStyle` supports `mindmap-balanced`, `mindmap-left`, `mindmap-right`, `logic-left`, `logic-right`, `tree-left`, `tree-right`, `org-down`, `org-up`, `fishbone-left`, `fishbone-right`, `timeline-vertical`, and `timeline-horizontal`.

`processOnStyle` supports `file`, `classic`, `warm`, `fresh`, `blue`, `green`, `purple`, `dark`, and `gray`. Use `file` to preserve POS theme fields such as `theme.background`, `centerTopic`, `secTopic`, `childTopic`, `floatingTopic`, and `connectionStyle`.

Canvas-style options mirror the demo panel:

- `canvasBackground` overrides the file/theme background. Use `"transparent"` for transparent SVG output.
- `hideCentralTopic` hides the root node while preserving the surrounding branch geometry.
- `watermark` can be `none`, `file`, or `mindport`.
- `horizontalGap`, `verticalGap`, and `preserveAttachedPositions` are useful for testing compact/loose spacing and free-branch layouts.

CLI:

```bash
mind-port render input.pos --out out.html --style processon --layout fishbone-left --processon-style file
mind-port render input.pos --out out.svg --style processon --layout org-down --processon-style blue
```

## HTML Output

`renderHtml()` wraps the SVG in a static, scrollable preview page.

```ts
const html = renderHtml(parsed, {
  title: "Roadmap",
  includeMetadataPanel: true
});
```

This is useful for server-side rendering, static previews, artifact pages, and file conversion pipelines.

## Viewer

The frameworkless viewer accepts either a parsed `MindPortDocument` or an SVG string. It supports zooming, reset, fit-to-viewport, and destruction.

```ts
const viewer = createMindPortViewer(container, parsed, { controls: true });
viewer.fit();
```

Security note: pass SVG generated by MindPort or trusted/sanitized SVG only.
